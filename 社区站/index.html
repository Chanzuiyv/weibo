📋 微博收藏整理工具

专为内容组打造的微博数据管理系统 —— 艺人/年份维度管理微博与评论，支持图片视频、链接失效检测、自动抓取正文、数据报告导出。纯网页单文件，Windows / Mac 通用，数据只存在你自己的电脑。

⬇️ 下载工具 🚀 快速开始

✨ 核心功能

从收藏整理到数据报告，一站式搞定

👤

艺人 / 年份管理

按艺人、年份组织微博数据，多账号登录，数据相互隔离，支持数据导入导出。

🖼️

图片 / 视频管理

微博配图与视频自动识别，支持批量上传、标记缺图、图频确认，图片防盗链自动处理。

🔗

链接失效检测

「只存链接」模式自动检测微博是否失效，自动抓取正文与图片，红框标记已删除内容。

💬

评论管理

区分艺人本人评论与粉丝评论，树形回复结构，支持评论编辑、删除、批量操作。

📊

数据报告

一键生成年度数据报告，包含微博数量、图片统计、评论分析等可视化内容。

🔒

隐私安全

纯前端单文件，数据存储在你本地浏览器（IndexedDB）或本地文件夹，不上传任何服务器。

🚀 快速开始

三步上手，零安装也能用基础功能

1

下载工具

点击上方「下载工具」按钮，得到一个 index.html 文件。

2

双击打开

直接双击 index.html，用浏览器打开即可使用。图片视频自动显示。

3

配置通道（可选）

💡 零安装即可使用基础功能：双击 index.html 打开，图片/视频自动显示，「完整保存」手贴模式全功能可用。只有「只存链接」的自动检测/抓取需要配置代理通道。

📖 使用教程

从导入数据到导出报告的完整流程

1. 注册与登录

  1. 打开工具后，点击「注册」创建账号（账号密码仅存在你本地浏览器）。
  2. 登录后选择「艺人」与「年份」，进入工作区。

2. 导入数据

  1. 点击左侧「①数据导入」。
  2. 选择包含微博/评论 xlsx 文件的文件夹（Chrome/Edge 支持一键选文件夹，其他浏览器可逐个选文件）。
  3. 工具自动解析并导入数据，可在 ②③ 页查看。

3. 管理微博

  1. 「②微博整理」：编辑文案、上传图片/视频、标记缺图、删除微博。
  2. 「③评论整理」：管理评论，区分艺人本人评论与粉丝评论。
  3. 支持「只存链接」模式：粘贴微博链接，自动检测存活并抓取正文/图片。

4. 配置自动检测通道（可选）

  1. 进入「④设置」→「外链与检测通道」。
  2. 三选一：
    • 油猴脚本：装 Tampermonkey 扩展 + 粘贴脚本，全自动，无需 Python。
    • Cloudflare Worker：部署一次，对方零安装全自动（推荐发给他人用）。
    • 本地代理：装 Python 后双击启动器，填 http://127.0.0.1:8787。
  3. 填好地址后点「保存」→「测试连通」。

5. 导出报告

  1. 整理完成后，点击「⑥数据报告」。
  2. 选择艺人和年份，生成可视化报告。
  3. 可导出为 HTML 或 Excel。
⚠️ 注意：数据存储在你本地浏览器（IndexedDB）。清除浏览器数据会丢失所有内容，建议定期使用「导出数据」功能备份。

❓ 常见问题

你可能想知道的

数据存在哪里？安全吗？
数据存储在你本地浏览器的 IndexedDB 中，或你选择的本地文件夹。不会上传到任何服务器，完全私密。但请注意：清除浏览器数据会丢失内容，建议定期导出备份。
需要装 Python 吗？
不需要。基础功能（图片显示、微博/评论管理）零安装即可使用。只有「只存链接」的自动检测/抓取需要配置通道，可选油猴脚本（无需 Python）或 Cloudflare Worker（对方零安装）。
Mac 能用吗？
完全可以。工具是纯网页单文件，Windows / Mac / Linux 通用。如果要本地代理，Mac 用 python3 weibo_proxy.py 或双击 启动代理.command。
图片显示不出来怎么办？
确保用双击 index.html 的方式打开（file:// 协议），或配置了有效的代理通道。如果个别图片仍不显示，可能是原图已被微博删除（外链永久失效）。
怎么分享给同事用？
把 index.html 文件发给对方即可。如果对方需要全自动检测功能，建议你先部署一个 Cloudflare Worker，把 Worker 地址告诉对方填进 ④设置页。对方不用装 Python、不用装扩展。
支持哪些浏览器？
推荐使用 Chrome、Edge、360、QQ、搜狗等 Chromium 内核浏览器（全功能支持）。Firefox、Safari 可使用核心功能，但批量导入/导出文件夹功能受限。
